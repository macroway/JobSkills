# 中文成稿检查

对 `08-职业规划完整初稿.md` 进行最后一轮编辑，再保存为 `职业规划完整.md`。目标是清楚、具体、像职业顾问写给当事人的方案，不是换词或增加修辞。

本清单吸收 `humanizer-zh` 中适用于职业咨询成稿的规则；**不迁入**“注入观点、第一人称情绪、允许跑题”等会削弱专业克制感的写法。

## 从 humanizer 迁入的规则（安全）

以下模式可删改，且不会改变岗位事实、来源编号、证据边界或主章节结构：

| 类别 | 识别信号 | 处理方式 |
| --- | --- | --- |
| 夸大意义 | 作为/标志着……的证明/体现/关键时刻、凸显其重要性、反映更广泛的 | 改成直接陈述岗位、能力或事实 |
| 宣传语 | 充满活力、深刻、致力于、无缝、直观、强大、令人叹为观止 | 改成具体动作、交付物或可观察结果 |
| 模糊归因 | 行业报告显示、专家认为、观察者指出、多个来源认为 | 改成来源编号；无出处则删或写“待确认” |
| 模型免责声明 | 根据可用信息、具体细节有限/稀缺 | 删除；有证据就写证据，没有就写“待确认”。保留界定岗位状态、访问日期或招聘窗口的具体日期。 |
| AI 高频词 | 此外、深入探讨、格局、至关重要、凸显、增强、培养、相互作用 | 仅在充当填充语时删或换成具体表述；不要机械删除有实际含义的词。 |
| 系动词回避 | 作为/代表/标志着/充当 X | 能写“是/有”就直接写 |
| 否定式排比 | 不是……而是……、不只是……而是……、不仅仅是……而是…… | 若只是修辞，拆成直接事实句；确有必要表达取舍时，保留清楚的对比。 |
| 三段式堆砌 | 三项并列口号、三项形容词堆叠 | 删除装饰性词，只保留影响决策的项目；任务步骤可保留完整顺序。 |
| 同义词循环 | 同一对象反复换称“该岗位/该角色/该职位” | 统一称呼，合并重复句 |
| 虚假范围 | 从 A 到 B，但 A、B 不构成真实尺度 | 改成明确列举 |
| 公式化收尾 | 尽管面临挑战……未来将继续……、激动人心的时代 | 改成有日期或证据的下一步 |
| 填充与过度限定 | 值得注意的是、在这个时间点、可能潜在地被认为 | 删或改成直接陈述 |
| 谄媚/聊天痕迹 | 好问题！、您说得完全正确、当然！、希望这对您有帮助 | 删除 |
| 格式噪音 | 过多破折号、粗体、表情符号、`**字段：**` 内联标题列表 | 改成普通句或表格 |

## 不迁入的 humanizer 规则

- 不主动加入第一人称情绪、幽默、锋芒或“允许混乱、跑题”的表达。
- 不因追求“更有人味”而删改来源编号、日期、岗位事实或证据。
- 不使用 humanizer 的 50 分质量评分替代本清单的内容自检。

## 编辑顺序

1. 保留所有可核验事实、来源编号、日期、链接、文件路径和能力证据。
2. 保留七个 `##` 主章节的名称与顺序：职业画像、岗位检索与职业地图、能力差距矩阵、成长路线、每周行动清单、求职策略与备选路径、来源与假设。只润色章节内部文字，不合并、删除、改名或调序。
3. 按上表扫描并删改 AI 套话、宣传语、模糊归因、模型免责声明和聊天痕迹。
4. 将模糊归因改为来源编号或可观察事实；没有证据时写“待确认”或删除。
5. 拆开装饰性的三段式口号和否定式排比；保留有实际顺序或取舍信息的列表，让句子长短自然变化。
6. 用具体动作和交付物替代空泛词（见上表“AI 高频词”“宣传语”）。
7. 把“作为/标志着……的证明”改成直接陈述；能写“是/有”就不要绕开系动词。
8. 删除公式化“挑战与未来展望”段；同一对象不刻意换同义词；“从 A 到 B”只保留真实尺度。
9. 删除过多破折号、粗体、表情符号、内联标题列表，以及“希望对你有帮助”“请告诉我”等对话痕迹。
10. 删除空泛积极收尾，例如“未来看起来光明”“激动人心的时代即将到来”。

## 自检

- 每一段是否能指出具体岗位、能力、证据、动作或日期？不能则重写或删除。
- 连续三个句子是否同样长、同样以“通过……”“从而……”收尾？调整其中一句。
- 是否把单个职位要求写成了普遍规律？改为带来源的样本描述。
- 是否改变了岗位事实、日期、链接、简历证据或七个主章节的名称与顺序？如有，恢复事实版本。
- 是否出现保证、夸张承诺或聊天收尾？删除。
- 是否残留“此外”“格局”“至关重要”“作为……的证明”等 AI 高频表达？替换或删除。
- 是否用“尽管面临挑战……”等模板段代替具体问题和下一步？改成有证据的表述。

## 精华版

从 `职业规划完整.md` 生成 `职业规划-精华版.md` 时，先阅读完整报告，再按下列顺序重写：

1. 开头先写 `## 当前状态与已有基础`，并按 `### 当前的状态`、`### 过往履历`、`### 你关注的点` 的顺序呈现。只转写支撑规划判断的信息；偏好必须明确归因于用户，未提供时如实写“未明确表达”。
2. 再回答用户提出的职业规划诉求。尽早给出主方向、备选方向和原因，不复述检索方法。
3. 只保留会改变用户下一步的事实、判断、时间节点和行动；删除来源编号、URL、本地路径、检索数量、原始 JD 摘录、验证日志和逐日任务表。
4. 把“能力差距”改成具体的下一步：先补什么、做出什么、怎样判断完成。保留 12 周的阶段节奏和会影响投递的日期，但不逐日罗列任务表。
5. 用自然、直接的中文写出已有基础与现实缺口。可以给出有根据的鼓励，例如“你的跨系统数据同步经历能直接放到数据开发简历里”；不要写“稳了”“一定能拿到”或空泛的打气话。
6. 最后扫一遍：按“从 humanizer 迁入的规则”删除宣传语、三段式口号、模糊归因、AI 高频词、过度破折号、粗体堆砌、内联标题列表、聊天结尾和“作为……的证明”等句式。混合长短句，不强行把每段写成同一模板；不加入 humanizer 式的主观情绪或第一人称感慨。
