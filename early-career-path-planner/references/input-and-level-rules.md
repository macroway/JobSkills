# 输入与职级规则

## 资料字段

| 字段 | 必填 | 提取与使用规则 |
| --- | --- | --- |
| 专业 | 是 | 写当前或最高相关专业；无法判断时向用户确认。 |
| 学历 | 是 | 写中职、专科、本科、硕士、博士等。 |
| 毕业时间 | 是 | 至少到年月；用于判断在读状态和倒排。 |
| 现有技能 | 是 | 写技能及课程、项目、实习、作品、证书或工作成果证据；没有时写“暂无可展示技能”。 |
| 兴趣 | 否 | 记录用户明确表达的兴趣领域、问题或工作内容；写入职业画像的“用户表达的偏好”。 |
| 职业偏好 | 否 | 记录行业、工作方式、愿意或不愿意承担的工作内容；写入职业画像的“用户表达的偏好”。 |
| 职业规划诉求 | 否 | 记录用户希望得到解答的自然语言问题；例如比较岗位、制定校招策略或规划申请步骤。必须逐项回应。 |
| 工作城市 | 否 | 用于本次岗位检索的城市样本；缺失时为北京。 |

支持的替代输入是 PDF、DOC/DOCX、JPEG、PNG 简历。简历必须能提取上述四项必填资料；若其中任何一项缺失，再以最少问题补齐。

不要索取或保存身份证号、详细住址、家庭收入、婚育信息、联系方式等与规划无关的信息。姓名只用于输出目录；缺失时用 `匿名用户`。

## 当前职级判定

优先级从高到低：明确相关全职工作年限 → 明确在读年级 → 根据毕业时间估算的在读状态。

| 当前状态 | 文件夹中的当前职级 | 努力方向 JD 工作年限 |
| --- | --- | --- |
| 大一 | 大一 | 0–1 年 |
| 大二 | 大二 | 0–1 年 |
| 大三 | 大三 | 1–3 年 |
| 大四或毕业前最后一年 | 大四/毕业前 | 1–3 年 |
| 研究生在读 | 研一/研二/研三；无法判定时“研究生在读” | 1–3 年 |
| 毕业后相关全职经验 0–1 年 | 工作0-1年 | 1–3 年 |
| 相关全职经验 1–3 年 | 工作1-3年 | 3–5 年 |
| 相关全职经验 3–5 年 | 工作3-5年 | 5–8 年 |

兼职、短期项目和实习不计为相关全职年限，但可以作为能力证据。用户已在职时，优先用其当前职责和项目判断“相关”，不要把无关全职经历直接折算为岗位等级。

这个表只给出要寻找的 JD 工作年限，不能替代本地 JD 正文的判断。读取候选 JD 的“工作年限”后，用下表归一化其职责尺度：0–1 年为校招，1–3 年为初级，3–5 年为中级，5–8 年为高级，8 年以上为专家/负责人。输出同时记录“目标工作年限”和所选 JD 的原始“职级/类型、工作年限”；二者不一致时说明原因。

如果只知道“在读”而无法确定是大一/大二还是大三及以上，询问年级，因为它会改变努力方向 JD 的工作年限。毕业时间已经能明确判断时，不重复追问。

## 文件夹安全命名

采用 `<姓名-当前职级-主方向岗位名称-YYYYMMDD-HHmmss>`。将所有路径不安全字符和连字符替换为中文顿号或下划线，去除前后空格；不使用简历中的电话、邮箱等信息作为文件夹名。
