# 风险策略分析师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 专家 |
| 工作年限 | 8 年以上 |

## 岗位概述

负责风险策略数据分析、规则效果评估与模型监控，支撑风控策略持续优化，负责关键业务方向或能力建设，推动战略拆解与长期价值落地。

## 主要职责

1. 结合业务目标与行业趋势，参与或负责中长期规划与关键方向拆解，明确能力建设路径与优先级。
2. 负责制定并推动业务指标体系搭建与日常监控，跟踪核心指标波动并及时识别异常与归因线索。
3. 负责牵头完成数据提取、清洗、统计分析与可视化呈现，输出结构化分析报告。
4. 围绕重点业务问题开展专题研究，提出可落地的优化建议并跟进效果验证。
5. 参与 A/B 实验或策略评估，负责制定并推动设计分析方案并输出客观结论。
6. 与产品、运营、技术等团队协作，负责制定并推动沉淀分析模板、口径文档与数据资产。
7. 负责关键领域的方法论沉淀、能力体系建设与跨团队影响力构建，推动组织专业能力持续提升。

## 任职要求

### 必备条件

- 具备 8 年以上数据分析相关全职工作经验，有互联网业务分析经验者优先。
- 扎实的统计学与数据分析基础，能运用常见分析方法解决业务问题。
- 熟练使用 SQL 进行数据查询与整合，具备 Excel 数据处理与可视化能力。
- 熟练使用 Python 或 R 进行数据分析与建模，具备数据清洗与探索性分析能力。
- 本科及以上学历，统计学、数学、计算机、经济学等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备战略规划、复杂问题分析与关键决策能力，能在跨团队协作中推动关键事项落地，能建立方法论并影响跨团队协作。

### 加分项

- 熟悉 Hive、Spark 等大数据环境或 BI 工具使用经验。
- 有用户增长、电商、广告等业务方向分析经验。
- 具备指标体系搭建、因果推断或用户画像分析实践经验。
