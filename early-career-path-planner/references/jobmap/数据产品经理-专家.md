# 数据产品经理｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 专家 |
| 工作年限 | 8 年以上 |

## 岗位概述

负责数据类产品或数据能力模块的需求设计与迭代，连接业务、数据与研发团队，推动指标体系、分析工具或数据平台能力落地，负责关键业务方向或能力建设，推动战略拆解与长期价值落地。

## 主要职责

1. 结合业务目标与行业趋势，参与或负责中长期规划与关键方向拆解，明确能力建设路径与优先级。
2. 调研业务数据需求，设计数据产品功能、指标口径与使用流程，输出 PRD 与原型。
3. 协同数据研发、算法与工程团队推进数据产品开发、联调与上线。
4. 跟踪数据产品使用情况与效果反馈，持续优化产品体验与数据准确性。
5. 负责制定并推动数据治理、权限管理与数据安全相关需求设计，保障合规可用。
6. 建立并推广组织级数据产品文档、使用指南与最佳实践，提升业务侧数据自助能力。
7. 负责关键领域的方法论沉淀、能力体系建设与跨团队影响力构建，推动组织专业能力持续提升。

## 任职要求

### 必备条件

- 具备 8 年以上产品经理或相关产品岗位全职工作经验，有互联网产品从战略规划到规模化落地的成功经验。
- 精通产品从需求分析到上线迭代的基本流程，能独立完成业务方向或关键技术领域需求设计与文档撰写。
- 熟练使用 Axure、Figma、墨刀等原型工具，具备扎实的数据分析与逻辑拆解能力。
- 沟通表达清晰，具备跨团队协作与项目推进能力，能在复杂场景中推动问题闭环。
- 本科及以上学历，计算机、信息管理、市场营销等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备战略规划、复杂问题分析与关键决策能力，能在跨团队协作中推动关键事项落地，能建立方法论并影响跨团队协作。

### 加分项

- 有 ToB/SaaS、电商、内容、AI 等垂直领域产品经验。
- 具备 SQL、Excel 数据分析或 A/B 实验相关实践经验。
- 作为核心负责人完成功能模块从 0 到 1 落地并持续迭代的案例。
