# 渗透测试工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 专家 |
| 工作年限 | 8 年以上 |

## 岗位概述

负责渗透测试、漏洞挖掘与攻击模拟，评估系统安全水位并推动风险整改闭环，负责关键业务方向或能力建设，推动战略拆解与长期价值落地。

## 主要职责

1. 结合业务目标与行业趋势，参与或负责中长期规划与关键方向拆解，明确能力建设路径与优先级。
2. 负责制定并推动安全评估、漏洞扫描与渗透测试，输出风险报告并推动整改闭环。
3. 建立并持续完善安全基线、访问控制与审计机制，提升系统整体安全防护能力。
4. 跟踪安全事件与威胁情报，负责制定并推动应急响应与溯源分析，降低安全风险影响。
5. 与研发、运维、合规团队协作，将安全要求融入研发流程与系统架构。
6. 建立并推广组织级安全规范、检查清单与培训材料，提升团队安全意识与治理能力。
7. 负责关键领域的方法论沉淀、能力体系建设与跨团队影响力构建，推动组织专业能力持续提升。

## 任职要求

### 必备条件

- 具备 8 年以上信息安全、应用安全或风控相关全职工作经验。
- 精通常见 Web 安全漏洞、网络攻击手法及防护思路。
- 精通安全评估、日志分析或合规检查的基本方法。
- 具备良好的逻辑思维、沟通协作能力与责任心。
- 本科及以上学历，计算机、网络安全等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备战略规划、复杂问题分析与关键决策能力，能在跨团队协作中推动关键事项落地，能建立方法论并影响跨团队协作。

### 加分项

- 持有 CISP、CISSP、CEH 等安全相关认证。
- 有 SDL、DevSecOps 或安全运营平台建设经验。
- 熟悉金融行业、互联网行业合规与安全审计要求。
