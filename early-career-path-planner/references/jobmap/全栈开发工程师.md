# 全栈开发工程师｜岗位职责描述

## 校招

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与前后端一体化功能模块的开发与维护，贯通需求理解、接口设计与页面实现，提升业务交付效率与系统一致性。

## 主要职责

1. 在指导下完成业务功能的前后端开发，包括接口设计、页面实现与联调测试。
2. 参与技术选型与模块架构设计，平衡开发效率、可维护性与系统性能。
3. 与产品、设计团队协作，快速验证方案并推动功能迭代上线。
4. 参与定位并修复全链路问题，保障功能稳定性与用户体验。
5. 参与沉淀通用组件、脚手架与开发规范，提升团队整体交付效率。

## 任职要求

### 必备条件

- 具备 0–1 年全栈开发相关全职工作经验，能在指导下参与模块级功能交付。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 掌握至少一种前端框架与一种后端开发语言，具备完整项目开发能力。
- 熟悉数据库设计、API 设计与常见 Web 开发模式。
- 具备良好的学习能力、问题解决能力与跨团队协作意识。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有 SaaS、管理后台或数据可视化项目经验相关实习或校园项目经历。
- 熟悉云部署、DevOps 或自动化测试流程相关实习或校园项目经历。
- 有从 0 到 1 搭建小型系统或内部工具的经验相关实习或校园项目经历。

## 中级

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责前后端全栈相关模块或子系统的设计开发与维护，保障系统性能、稳定性与代码质量，对交付效率与技术方案结果负责。

## 主要职责

1. 主导复杂业务模块的技术方案设计与编码实现，保障前后端全栈架构合理性与可维护性。
2. 负责代码评审、技术难点攻关与线上问题排查，推动性能优化、稳定性改进与缺陷闭环。
3. 与产品、测试、运维等团队深度协作，推进需求落地、接口联调与高质量发布。
4. 参与或主导技术规范、工程化建设与组件/服务复用，提升团队研发效率。
5. 输出技术设计文档与复盘总结，沉淀最佳实践并辅导初级工程师成长。

## 任职要求

### 必备条件

- 具备 3–5 年全栈开发或相关技术全职工作经验。
- 精通前后端全栈核心技术，能独立负责复杂模块或子系统的设计与开发。
- 熟悉常见设计模式、数据结构与算法，具备良好的编码规范与问题定位能力。
- 具备出色的跨团队协作与沟通能力，能在项目压力下保障交付质量。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有大型互联网高并发系统开发经验。
- 熟悉 CI/CD、容器化或微服务架构。
- 有技术分享、Code Review 牵头或工程化建设经验。
