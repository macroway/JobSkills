# 前端开发工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 专家 |
| 工作年限 | 8 年以上 |

## 岗位概述

负责 Web/H5 等前端模块的设计开发与维护，保障页面性能、交互体验与代码质量，协同产品与后端团队高质量交付业务功能，负责关键业务方向或能力建设，推动战略拆解与长期价值落地。

## 主要职责

1. 结合业务目标与行业趋势，参与或负责中长期规划与关键方向拆解，明确能力建设路径与优先级。
2. 根据产品需求与 UI 设计稿，负责牵头完成前端页面与交互功能开发，保障高保真还原。
3. 负责制定并推动前端组件封装、代码规范与工程化建设，提升开发效率与可维护性。
4. 与后端协作完成接口联调，定位并修复前后端集成问题，保障功能稳定上线。
5. 负责制定并推动前端性能优化、兼容性适配与线上问题排查，持续改进用户体验与系统稳定性。
6. 编写必要的技术文档，负责制定并推动代码评审，沉淀可复用组件与最佳实践。
7. 负责关键领域的方法论沉淀、能力体系建设与跨团队影响力构建，推动组织专业能力持续提升。

## 任职要求

### 必备条件

- 具备 8 年以上前端开发相关全职工作经验，有多个公司级项目独立交付或技术攻坚经验。
- 精通 HTML、CSS、JavaScript/TypeScript，精通 ES6+ 语法与常见前端开发模式。
- 熟练使用 Vue 或 React 等主流框架，精通前端工程化工具（Webpack/Vite 等）。
- 精通 Git 协作流程，具备良好的编码习惯、问题定位与沟通能力。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备战略规划、复杂问题分析与关键决策能力，能在跨团队协作中推动关键事项落地，能建立方法论并影响跨团队协作。

### 加分项

- 有小程序、跨端开发或 Node.js 中间层开发经验。
- 熟悉前端性能优化、自动化测试或 CI/CD 流程。
- 有组件库建设、低代码平台或 AI 辅助开发工具使用经验。
