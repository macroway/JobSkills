# 游戏UI设计师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 专家 |
| 工作年限 | 8 年以上 |

## 岗位概述

负责游戏相关策划、美术或运营模块工作，支撑游戏产品玩法设计、内容生产与玩家体验优化，推动游戏项目高质量上线与持续运营，负责关键业务方向或能力建设，推动战略拆解与长期价值落地。

## 主要职责

1. 结合业务目标与行业趋势，参与或负责中长期规划与关键方向拆解，明确能力建设路径与优先级。
2. 负责制定并推动游戏玩法、关卡、数值或内容设计，输出可执行的策划文档与配置方案。
3. 建立玩家反馈机制，跟踪反馈与核心运营数据，分析体验问题并提出优化方向。
4. 与程序、美术、测试团队协作，推动功能开发、资源制作与版本迭代。
5. 负责版本测试、平衡性调整与上线活动支持，保障交付质量与玩家体验。
6. 建立并推广组织级设计规范、模板与复盘文档，提升团队协作效率与内容产出质量。
7. 负责关键领域的方法论沉淀、能力体系建设与跨团队影响力构建，推动组织专业能力持续提升。

## 任职要求

### 必备条件

- 具备 8 年以上游戏行业相关全职工作经验，热爱游戏并精通主流品类特点。
- 具备扎实的专业基础与良好的逻辑思维，能独立完成业务方向或关键技术领域工作交付。
- 具备良好的沟通协作能力与责任心，能在快节奏项目中推进落地。
- 熟练使用岗位相关工具与文档规范，具备较强的学习能力。
- 本科及以上学历，相关专业优先；学历要求可根据实际招聘要求调整。
- 具备战略规划、复杂问题分析与关键决策能力，能在跨团队协作中推动关键事项落地，能建立方法论并影响跨团队协作。

### 加分项

- 作为核心负责人完成游戏项目上线或长线运营经验。
- 深度体验过多款主流游戏并能清晰表达设计思路。
- 有玩家社区运营或竞品分析经验。
