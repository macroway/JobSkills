# 游戏美术设计师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 高级 |
| 工作年限 | 5–8 年 |

## 岗位概述

负责游戏相关策划、美术或运营模块工作，支撑游戏产品玩法设计、内容生产与玩家体验优化，推动游戏项目高质量上线与持续运营，推动关键项目落地与方法沉淀。

## 主要职责

1. 主导游戏玩法、关卡、数值或内容设计，输出可执行的策划文档与配置方案。
2. 建立玩家反馈机制，跟踪反馈与核心运营数据，分析体验问题并提出优化方向。
3. 与程序、美术、测试团队协作，推动功能开发、资源制作与版本迭代。
4. 负责版本测试、平衡性调整与上线活动支持，保障交付质量与玩家体验。
5. 沉淀并推广设计规范、模板与复盘文档，提升团队协作效率与内容产出质量。
6. 辅导初级成员或协作伙伴，沉淀方法论、规范与最佳实践，提升团队整体专业能力与交付效率。

## 任职要求

### 必备条件

- 具备 5–8 年游戏行业相关全职工作经验，热爱游戏并熟悉主流品类特点。
- 具备扎实的专业基础与良好的逻辑思维，能独立完成核心领域或复杂项目工作交付。
- 具备良好的沟通协作能力与责任心，能在快节奏项目中推进落地。
- 熟练使用岗位相关工具与文档规范，具备较强的学习能力。
- 本科及以上学历，相关专业优先；学历要求可根据实际招聘要求调整。
- 具备复杂问题分析与决策能力，能在跨团队协作中推动关键事项落地，并辅导初级成员成长。

### 加分项

- 主导过完整游戏项目上线或长线运营经验。
- 深度体验过多款主流游戏并能清晰表达设计思路。
- 有玩家社区运营或竞品分析经验。
