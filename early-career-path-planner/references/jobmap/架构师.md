# 架构师｜岗位职责描述

## 校招

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，在 1–3 年经验阶段，以高级开发骨干角色参与系统方案设计、技术选型与核心模块开发，为架构能力建设积累经验。

## 主要职责

1. 协助核心业务模块的技术方案设计与开发，保障架构合理性与交付质量。
2. 参与技术评审、代码评审与难点攻关，协助团队解决复杂技术问题。
3. 与产品、测试、运维团队协作，推动需求落地、质量保障与线上稳定性改进。
4. 参与技术规范、最佳实践与知识分享，帮助团队成员共同成长。
5. 跟踪行业技术趋势，在协助领域内探索并落地可提升效率与质量的技术方案。

## 任职要求

### 必备条件

- 具备 0–1 年相关技术岗位全职工作经验，有独立负责模块或子系统的经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 技术基础扎实，能在所负责领域独立完成方案设计与开发交付。
- 具备良好的沟通表达能力、逻辑思维与跨团队协作意识。
- 有较强的问题分析与解决能力，能在压力下保障交付质量。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 有技术分享、导师辅导或小组协作牵头经验相关实习或校园项目经历。
- 在某一技术方向有较深积累（如性能优化、架构设计、工程化等）相关实习或校园项目经历。
- 参与过项目从设计到上线的成功经验相关实习或校园项目经历。
