# PHP开发工程师｜岗位职责描述

## 校招

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与服务端业务模块的设计、开发与维护，保障系统稳定性、性能与数据安全，支撑业务功能快速迭代与规模化运行。

## 主要职责

1. 在指导下根据产品需求完成后端接口设计与开发，保障功能正确性、可扩展性与代码质量。
2. 参与数据库表结构设计、SQL 优化与缓存策略设计，提升系统性能与数据一致性。
3. 与前端、测试、运维团队协作，完成联调、测试支持与线上问题排查修复。
4. 参与系统架构讨论与技术方案评审，推动模块级重构与稳定性改进。
5. 参与编写接口文档与技术说明，参与代码评审，沉淀开发规范与可复用能力。

## 任职要求

### 必备条件

- 具备 0–1 年 PHP 开发全职工作经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 掌握 PHP 及常见框架（如 Laravel、ThinkPHP 等）。
- 熟悉 MySQL 数据库与 Linux 部署环境。
- 具备良好的编码习惯与业务交付能力。
- 本科及以上学历，计算机相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 有微服务、分布式系统或高并发场景开发经验相关实习或校园项目经历。
- 熟悉 Docker、K8s 等容器化部署与 CI/CD 流程相关实习或校园项目经历。
- 有消息队列、搜索引擎或大数据组件使用经验相关实习或校园项目经历。

## 中级

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责PHP Web相关模块或子系统的设计开发与维护，保障系统性能、稳定性与代码质量，对交付效率与技术方案结果负责。

## 主要职责

1. 主导复杂业务模块的技术方案设计与编码实现，保障PHP Web架构合理性与可维护性。
2. 负责代码评审、技术难点攻关与线上问题排查，推动性能优化、稳定性改进与缺陷闭环。
3. 与产品、测试、运维等团队深度协作，推进需求落地、接口联调与高质量发布。
4. 参与或主导技术规范、工程化建设与组件/服务复用，提升团队研发效率。
5. 输出技术设计文档与复盘总结，沉淀最佳实践并辅导初级工程师成长。

## 任职要求

### 必备条件

- 具备 3–5 年PHP开发或相关技术全职工作经验。
- 精通PHP Web核心技术，能独立负责复杂模块或子系统的设计与开发。
- 熟悉常见设计模式、数据结构与算法，具备良好的编码规范与问题定位能力。
- 具备出色的跨团队协作与沟通能力，能在项目压力下保障交付质量。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有大型互联网高并发系统开发经验。
- 熟悉 CI/CD、容器化或微服务架构。
- 有技术分享、Code Review 牵头或工程化建设经验。
