# MLOps工程师｜岗位职责描述

## 校招

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与机器学习平台的工程化建设，涵盖模型训练、部署、监控与流水线自动化，保障 AI 系统稳定运行。

## 主要职责

1. 协助服务器、网络、数据库或云资源的日常运维、监控告警与巡检，保障系统可用性。
2. 参与故障应急响应、问题定位与恢复，编写故障报告并推动根因修复与预防改进。
3. 执行发布变更、容量评估与性能优化，保障变更过程可控、风险可追踪。
4. 与研发、测试、安全团队协作，完善运维规范、自动化脚本与文档体系。
5. 参与运维平台、监控体系或自动化工具建设，提升运维效率与标准化水平。

## 任职要求

### 必备条件

- 具备 0–1 年运维、DevOps 或 SRE 相关全职工作经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 熟悉 Linux 操作系统、网络基础与常见中间件运维。
- 了解监控告警、日志分析与故障排查的基本方法。
- 具备良好的责任心、抗压能力与跨团队协作意识。
- 本科及以上学历，计算机、网络工程等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 熟悉 Docker、K8s、Terraform 等云原生技术相关实习或校园项目经历。
- 有 Python/Shell 自动化脚本开发经验相关实习或校园项目经历。
- 有大规模分布式系统或高可用架构运维经验相关实习或校园项目经历。

## 中级

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责MLOps相关算法方案设计、模型训练优化与业务落地，对模型效果与工程化交付结果负责。

## 主要职责

1. 主导MLOps业务问题的算法建模与方案设计，完成特征工程、模型训练与效果评估。
2. 负责离线/在线实验设计与迭代优化，分析核心指标并推动模型性能持续提升。
3. 与工程团队协作完成模型部署、服务化与推理优化，保障线上效果与资源效率。
4. 跟踪领域前沿技术与论文成果，将可落地的技术改进引入业务场景。
5. 沉淀实验记录、模型文档与评估规范，指导初级算法工程师提升研发质量。

## 任职要求

### 必备条件

- 具备 3–5 年算法、机器学习或数据挖掘全职工作经验。
- 扎实的数学、统计与机器学习基础，熟悉常见模型原理与评估方法。
- 熟悉模型训练流水线、特征平台与模型监控运维体系。
- 熟练使用 Python 及 PyTorch/TensorFlow 等框架，能独立主导模型开发与实验。
- 具备良好的业务理解、逻辑思维与跨团队协作能力。
- 硕士及以上学历，计算机、数学、统计学等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 在推荐、搜索、NLP、CV、语音或大模型等方向有实际项目经验。
- 熟悉分布式训练、推理优化或 MLOps 实践。
- 有顶会论文、算法竞赛获奖或开源贡献。
