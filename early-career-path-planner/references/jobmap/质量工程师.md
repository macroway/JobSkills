# 质量工程师｜岗位职责描述

## 校招

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与产品质量体系建设、过程质量监控与改进推动，协同研发团队提升交付质量与稳定性。

## 主要职责

1. 参与根据需求文档制定测试计划与测试用例，执行功能、接口、回归等测试并输出测试报告。
2. 跟踪缺陷生命周期，推动问题定位、修复验证与闭环管理。
3. 参与自动化测试脚本开发与维护，提升测试效率与覆盖率。
4. 与产品、开发团队协作，参与需求评审与上线验收，保障版本质量。
5. 参与沉淀测试规范、用例库与常见问题清单，持续改进测试流程与质量保障体系。

## 任职要求

### 必备条件

- 具备 0–1 年软件测试或测试开发相关全职工作经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 熟悉软件测试理论与流程，能在指导下完成模块级测试设计与执行。
- 了解至少一种自动化测试工具或脚本语言，有接口/UI 自动化经验者优先。
- 具备良好的逻辑思维、沟通协作能力与责任心。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 有性能测试、安全测试或游戏测试相关经验相关实习或校园项目经历。
- 熟悉 CI/CD 流程与测试左移实践相关实习或校园项目经历。
- 有测试平台或质量度量体系建设经验相关实习或校园项目经历。

## 中级

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责质量工程师相关测试策略制定、用例设计与质量保障，对发布质量与缺陷闭环负责，能主导复杂场景的质量风险管控。

## 主要职责

1. 主导测试方案与用例设计，覆盖功能、接口、兼容性及回归测试，保障核心链路质量。
2. 负责缺陷定位、跟踪与闭环管理，推动研发修复并验证上线效果。
3. 参与或主导自动化测试、性能测试或专项测试能力建设，提升测试效率与覆盖率。
4. 与产品、研发、运维团队协作，参与需求评审与发布评审，识别并管控质量风险。
5. 输出测试报告与质量复盘，沉淀测试规范、工具与可复用测试资产。

## 任职要求

### 必备条件

- 具备 3–5 年软件测试或质量保障全职工作经验。
- 熟悉软件测试理论与全流程，能独立负责复杂模块或项目的质量保障工作。
- 熟练使用常见测试工具与缺陷管理平台，具备自动化或性能测试实践经验。
- 具备良好的逻辑思维、沟通协作与问题定位能力。
- 本科及以上学历，计算机相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有互联网业务测试或 CI/CD 集成测试经验。
- 熟悉接口测试、安全测试或游戏专项测试。
- 有测试框架开发或质量平台建设经验。
