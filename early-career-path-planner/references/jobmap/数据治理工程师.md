# 数据治理工程师｜岗位职责描述

## 校招

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与数据标准、质量、元数据与安全治理体系建设，提升数据资产可用性与合规水平。

## 主要职责

1. 参与业务指标体系搭建与日常监控，跟踪核心指标波动并及时识别异常与归因线索。
2. 在指导下完成数据提取、清洗、统计分析与可视化呈现，输出结构化分析报告。
3. 参与围绕重点业务问题开展专题研究，提出可落地的优化建议并跟进效果验证。
4. 参与 A/B 实验或策略评估，协助设计分析方案并输出客观结论。
5. 与产品、运营、技术等团队协作，沉淀分析模板、口径文档与数据资产。

## 任职要求

### 必备条件

- 具备 0–1 年数据分析相关全职工作经验，有互联网业务分析经验者优先。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 扎实的统计学与数据分析基础，能运用常见分析方法解决业务问题。
- 了解 SQL 进行数据查询与整合，具备 Excel 数据处理与可视化能力。
- 掌握 Python 或 R 中至少一种工具，具备数据清洗与探索性分析能力。
- 本科及以上学历，统计学、数学、计算机、经济学等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 熟悉 Hive、Spark 等大数据环境或 BI 工具使用经验相关实习或校园项目经历。
- 有用户增长、电商、广告等业务方向分析经验相关实习或校园项目经历。
- 具备指标体系搭建、因果推断或用户画像分析实践经验相关实习或校园项目经历。

## 中级

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责数据治理工程师相关数据分析、指标体系或数据工程建设，将数据能力转化为业务决策支撑，对分析质量与落地效果负责。

## 主要职责

1. 主导数据仓库/数据管道/BI 报表的设计开发与维护，保障数据准确性与时效性。
2. 独立负责复杂数据提取、清洗、建模分析与可视化呈现，输出结构化分析报告与策略建议。
3. 围绕重点业务问题开展专题研究，提出可落地的优化方案并跟进效果验证。
4. 主导 A/B 实验或策略评估设计，输出客观结论并推动业务团队采纳数据驱动决策。
5. 与产品、运营、技术等团队深度协作，沉淀分析模板、口径文档与数据资产。

## 任职要求

### 必备条件

- 具备 3–5 年数据分析、数据开发或商业分析全职工作经验。
- 熟悉数据仓库建模、ETL 流程与数据质量管控，能独立负责数据工程项目。
- 熟练使用 SQL，掌握 Python/R 中至少一种工具，具备数据建模与可视化能力。
- 具备出色的业务理解、沟通表达与跨团队项目推进能力。
- 本科及以上学历，统计学、数学、计算机、经济学等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 熟悉 Hive、Spark 等大数据环境或 Tableau、Power BI 等 BI 工具。
- 有用户增长、电商、金融等业务方向分析经验。
- 有指标体系、数据仓库或数据治理实践经验。
