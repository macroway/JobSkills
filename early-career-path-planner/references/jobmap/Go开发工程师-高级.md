# Go开发工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 高级 |
| 工作年限 | 5–8 年 |

## 岗位概述

负责服务端业务模块的设计、开发与维护，保障系统稳定性、性能与数据安全，支撑业务功能快速迭代与规模化运行，推动关键项目落地与方法沉淀。

## 主要职责

1. 根据产品需求完成后端接口设计与开发，保障功能正确性、可扩展性与代码质量。
2. 主导数据库表结构设计、SQL 优化与缓存策略设计，提升系统性能与数据一致性。
3. 与前端、测试、运维团队协作，完成联调、测试支持与线上问题排查修复。
4. 主导系统架构讨论与技术方案评审，推动模块级重构与稳定性改进。
5. 编写接口文档与技术说明，主导代码评审，沉淀开发规范与可复用能力。
6. 辅导初级成员或协作伙伴，沉淀方法论、规范与最佳实践，提升团队整体专业能力与交付效率。

## 任职要求

### 必备条件

- 具备 5–8 年 Go 语言后端开发全职工作经验。
- 熟练掌握 Go 语言及常见 Web/微服务框架，具备并发编程基础。
- 熟悉 MySQL、Redis、消息队列等常用组件。
- 具备良好的系统设计意识与工程化实践能力。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备复杂问题分析与决策能力，能在跨团队协作中推动关键事项落地，并辅导初级成员成长。

### 加分项

- 有微服务、分布式系统或高并发场景开发经验。
- 熟悉 Docker、K8s 等容器化部署与 CI/CD 流程。
- 有消息队列、搜索引擎或大数据组件使用经验。
