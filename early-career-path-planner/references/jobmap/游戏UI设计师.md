# 游戏UI设计师｜岗位职责描述

## 校招

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与游戏相关策划、美术或运营模块工作，支撑游戏产品玩法设计、内容生产与玩家体验优化，推动游戏项目高质量上线与持续运营。

## 主要职责

1. 参与游戏玩法、关卡、数值或内容设计，输出可执行的策划文档与配置方案。
2. 跟踪玩家反馈与核心运营数据，分析体验问题并提出优化方向。
3. 与程序、美术、测试团队协作，推动功能开发、资源制作与版本迭代。
4. 参与版本测试、平衡性调整与上线活动支持，保障交付质量与玩家体验。
5. 参与沉淀设计规范、模板与复盘文档，提升团队协作效率与内容产出质量。

## 任职要求

### 必备条件

- 具备 0–1 年游戏行业相关全职工作经验，热爱游戏并了解主流品类特点。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 具备扎实的专业基础与良好的逻辑思维，能在指导下完成模块级工作交付。
- 具备良好的沟通协作能力与责任心，能在快节奏项目中推进落地。
- 了解岗位相关工具与文档规范，具备较强的学习能力。
- 本科及以上学历，相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 参与过游戏项目上线或长线运营经验相关实习或校园项目经历。
- 深度体验过多款主流游戏并能清晰表达设计思路相关实习或校园项目经历。
- 有玩家社区运营或竞品分析经验相关实习或校园项目经历。

## 中级

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责游戏UI设计师相关视觉/交互/体验设计，保障设计质量与业务目标一致，对用户体验与交付效率负责。

## 主要职责

1. 主导复杂业务场景的设计方案输出，包括信息架构、交互流程、视觉稿与动效规范。
2. 与产品、研发紧密协作，参与需求评审并推动设计高保真落地，保障体验一致性。
3. 建立并维护设计规范、组件库与设计系统，提升团队设计效率与品牌统一性。
4. 通过用户反馈、可用性测试与数据分析驱动设计迭代，持续优化体验指标。
5. 输出设计复盘与经验沉淀，指导初级设计师提升专业能力与交付质量。

## 任职要求

### 必备条件

- 具备 3–5 年UI/UX/视觉/交互设计全职工作经验。
- 精通 Figma、Sketch 等设计工具，能独立负责复杂项目的设计交付。
- 具备扎实的交互、视觉或动效专业能力，关注细节与用户体验。
- 具备出色的沟通协作、需求理解与跨团队推进能力。
- 本科及以上学历，设计、美术、人机交互等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有互联网 C 端/B 端产品设计经验。
- 有设计系统、组件库建设经验。
- 有用户研究配合或 A/B 测试驱动设计优化经验。
