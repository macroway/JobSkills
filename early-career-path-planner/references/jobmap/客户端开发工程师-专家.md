# 客户端开发工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 专家 |
| 工作年限 | 8 年以上 |

## 岗位概述

负责移动端 App 功能模块的开发与维护，保障用户体验、性能与稳定性，协同产品、设计与后端团队完成高质量交付，负责关键业务方向或能力建设，推动战略拆解与长期价值落地。

## 主要职责

1. 结合业务目标与行业趋势，参与或负责中长期规划与关键方向拆解，明确能力建设路径与优先级。
2. 根据产品需求完成移动端功能开发与 UI 还原，保障交互流畅与版本稳定。
3. 负责制定并推动客户端架构优化、组件封装与性能调优，提升启动速度、流畅度与崩溃率表现。
4. 与后端协作完成接口联调，定位并修复客户端线上问题，保障核心链路可用性。
5. 跟进系统版本适配、权限变更与应用商店发布流程，保障合规上线。
6. 负责制定并推动代码评审与技术文档编写，沉淀可复用组件与开发规范。
7. 负责关键领域的方法论沉淀、能力体系建设与跨团队影响力构建，推动组织专业能力持续提升。

## 任职要求

### 必备条件

- 具备 8 年以上移动端开发相关全职工作经验，有多个公司级 App 或平台项目独立负责经验。
- 熟练掌握对应平台开发语言与框架，能独立完成业务方向或关键技术领域功能开发。
- 精通移动端常见性能优化、网络通信、数据存储与调试手段。
- 具备良好的编码习惯、问题定位能力与跨团队协作意识。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备战略规划、复杂问题分析与关键决策能力，能在跨团队协作中推动关键事项落地，能建立方法论并影响跨团队协作。

### 加分项

- 有跨平台开发（Flutter/React Native 等）经验。
- 熟悉音视频、推送、埋点或热修复等相关技术。
- 有应用性能监控（APM）与线上问题治理经验。
