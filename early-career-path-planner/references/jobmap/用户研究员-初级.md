# 用户研究员｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 初级 |
| 工作年限 | 1–3 年 |

## 岗位概述

通过用户访谈、可用性测试与行为数据分析，洞察用户需求与使用场景，为产品设计与业务决策提供可落地的研究结论与体验优化建议。

## 主要职责

1. 参与用户研究项目设计与执行，包括访谈、问卷、可用性测试等，输出研究报告与关键洞察。
2. 协助建立用户画像、旅程地图与需求优先级，为产品、设计、运营团队提供决策输入。
3. 跟踪产品上线后的用户反馈与行为数据，识别体验问题并提出改进方向。
4. 与产品、设计、研发团队协作，推动研究结论转化为具体的产品与体验优化方案。
5. 沉淀研究方法论、访谈提纲与分析模板，提升团队用户研究效率与质量。

## 任职要求

### 必备条件

- 具备 1–3 年用户研究、市场研究或体验研究相关全职工作经验。
- 熟悉定性/定量研究方法，能独立完成调研设计、样本招募与结论输出。
- 具备良好的沟通引导能力与逻辑思维，能清晰呈现研究发现与建议。
- 熟练使用常见调研与分析工具，具备基础数据整理与可视化能力。
- 本科及以上学历，心理学、社会学、人机交互、市场营销等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有 SPSS、Python、R 等数据分析工具使用经验。
- 熟悉互联网 C 端/B 端产品研究场景。
- 具备可用性测试实验室运营或眼动/热力图等工具使用经验。
