# 电商运营｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 初级 |
| 工作年限 | 1–3 年 |

## 岗位概述

负责电商平台的商品、流量与交易运营，提升 GMV、转化率与用户购物体验。

## 主要职责

1. 参与运营策略制定与执行，围绕拉新、活跃、转化、留存等目标推进具体方案落地。
2. 跟踪核心运营数据，分析活动或策略效果，输出复盘报告并持续优化。
3. 策划并执行运营活动、内容计划或用户触达方案，提升用户参与度和业务转化。
4. 与产品、设计、市场、客服等团队协作，推动运营需求闭环与体验改进。
5. 沉淀运营 SOP、活动模板与方法论，提升团队运营效率与可复制性。

## 任职要求

### 必备条件

- 具备 1–3 年互联网运营相关全职工作经验，有独立负责模块或项目的经验。
- 具备数据敏感度，能使用 Excel、SQL 等工具进行基础数据分析。
- 具备良好的文案能力、执行力与跨团队沟通协作能力。
- 对互联网业务模式有基本理解，能快速学习并适应业务变化。
- 本科及以上学历，市场营销、新闻传播、电子商务等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有电商、内容、社区、直播或增长运营相关经验。
- 熟悉 A/B 测试、用户分层或私域运营方法。
- 有从 0 到 1 搭建运营体系或爆款活动案例。
