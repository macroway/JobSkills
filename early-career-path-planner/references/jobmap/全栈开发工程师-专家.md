# 全栈开发工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 专家 |
| 工作年限 | 8 年以上 |

## 岗位概述

负责前后端一体化功能模块的开发与维护，贯通需求理解、接口设计与页面实现，提升业务交付效率与系统一致性，负责关键业务方向或能力建设，推动战略拆解与长期价值落地。

## 主要职责

1. 结合业务目标与行业趋势，参与或负责中长期规划与关键方向拆解，明确能力建设路径与优先级。
2. 负责牵头完成业务功能的前后端开发，包括接口设计、页面实现与联调测试。
3. 负责制定并推动技术选型与模块架构设计，平衡开发效率、可维护性与系统性能。
4. 与产品、设计团队协作，快速验证方案并推动功能迭代上线。
5. 定位并修复全链路问题，保障功能稳定性与用户体验。
6. 建立并推广组织级通用组件、脚手架与开发规范，提升团队整体交付效率。
7. 负责关键领域的方法论沉淀、能力体系建设与跨团队影响力构建，推动组织专业能力持续提升。

## 任职要求

### 必备条件

- 具备 8 年以上全栈开发相关全职工作经验，能独立负责业务方向或关键技术领域功能交付。
- 熟练掌握至少一种前端框架与一种后端开发语言，具备完整项目开发能力。
- 精通数据库设计、API 设计与常见 Web 开发模式。
- 具备良好的学习能力、问题解决能力与跨团队协作意识。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备战略规划、复杂问题分析与关键决策能力，能在跨团队协作中推动关键事项落地，能建立方法论并影响跨团队协作。

### 加分项

- 有 SaaS、管理后台或数据可视化项目经验。
- 熟悉云部署、DevOps 或自动化测试流程。
- 有从 0 到 1 搭建小型系统或内部工具的经验。
