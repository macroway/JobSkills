# 用户研究员｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责用户洞察研究、体验评估与需求验证，为产品与设计决策提供可落地的用户证据，对研究质量与业务影响力负责。

## 主要职责

1. 主导用户访谈、可用性测试、问卷调研等研究方法设计与执行，输出结构化研究报告与洞察结论。
2. 建立用户画像、旅程地图与痛点分析框架，识别关键体验问题并推动产品优化落地。
3. 与产品、设计、运营团队深度协作，将研究发现转化为可执行的需求建议与体验改进方案。
4. 负责研究项目全流程管理，包括目标定义、样本招募、数据采集、分析与结论汇报。
5. 沉淀研究方法论、模板与知识库，提升团队用户研究效率与结论可信度。

## 任职要求

### 必备条件

- 具备 3–5 年用户研究、用研或 UX 研究全职工作经验。
- 熟练掌握定性、定量研究方法，能独立设计并执行完整研究项目。
- 具备出色的访谈引导、数据分析与报告撰写能力，能将复杂发现转化为业务语言。
- 熟悉用户体验评估工具与常用调研平台，具备跨团队协作与项目推进能力。
- 本科及以上学历，心理学、社会学、人机交互、设计等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有互联网 C 端/B 端产品用研经验。
- 具备眼动、热力图或行为数据分析工具使用经验。
- 有 A/B 测试配合或体验度量体系建设经验。
