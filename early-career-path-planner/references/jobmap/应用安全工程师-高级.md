# 应用安全工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 高级 |
| 工作年限 | 5–8 年 |

## 岗位概述

负责应用系统安全评估、代码审计与漏洞治理，推动安全能力融入研发全流程，推动关键项目落地与方法沉淀。

## 主要职责

1. 主导安全评估、漏洞扫描与渗透测试，输出风险报告并推动整改闭环。
2. 建立并持续完善安全基线、访问控制与审计机制，提升系统整体安全防护能力。
3. 跟踪安全事件与威胁情报，主导应急响应与溯源分析，降低安全风险影响。
4. 与研发、运维、合规团队协作，将安全要求融入研发流程与系统架构。
5. 沉淀并推广安全规范、检查清单与培训材料，提升团队安全意识与治理能力。
6. 辅导初级成员或协作伙伴，沉淀方法论、规范与最佳实践，提升团队整体专业能力与交付效率。

## 任职要求

### 必备条件

- 具备 5–8 年信息安全、应用安全或风控相关全职工作经验。
- 熟悉常见 Web 安全漏洞、网络攻击手法及防护思路。
- 熟悉安全评估、日志分析或合规检查的基本方法。
- 具备良好的逻辑思维、沟通协作能力与责任心。
- 本科及以上学历，计算机、网络安全等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备复杂问题分析与决策能力，能在跨团队协作中推动关键事项落地，并辅导初级成员成长。

### 加分项

- 持有 CISP、CISSP、CEH 等安全相关认证。
- 有 SDL、DevSecOps 或安全运营平台建设经验。
- 熟悉金融行业、互联网行业合规与安全审计要求。
