# 技术产品经理｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与技术平台、开发者工具或基础设施类产品的规划与迭代，连接业务与技术团队，推动平台能力标准化与效率提升。

## 主要职责

1. 参与用户调研、竞品分析与业务需求梳理，输出清晰的需求文档、流程图与原型方案，支撑产品规划与版本迭代。
2. 参与跟进需求评审、开发联调、测试验收与上线发布，协调设计、研发、测试等团队保障交付质量与进度。
3. 跟踪产品核心数据与用户反馈，分析功能使用效果，提出优化建议并推动落地，形成复盘结论。
4. 参与跨团队沟通与项目推进，及时同步风险与进展，保障需求理解一致、问题闭环处理。
5. 参与沉淀常用需求模板、分析框架与产品文档规范，提升团队协作效率与方案可复用性。

## 任职要求

### 必备条件

- 具备 0–1 年产品经理或相关产品岗位全职工作经验，有互联网产品落地经验者优先。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 熟悉产品从需求分析到上线迭代的基本流程，能在指导下完成模块级需求设计与文档撰写。
- 了解 Axure、Figma、墨刀等原型工具，具备基础数据分析与逻辑拆解能力。
- 沟通表达清晰，具备跨团队协作与项目推进能力，能在复杂场景中推动问题闭环。
- 本科及以上学历，计算机、信息管理、市场营销等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 有 ToB/SaaS、电商、内容、AI 等垂直领域产品经验相关实习或校园项目经历。
- 具备 SQL、Excel 数据分析或 A/B 实验相关实践经验相关实习或校园项目经历。
- 参与过功能模块从 0 到 1 落地并持续迭代的案例相关实习或校园项目经历。
