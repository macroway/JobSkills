# 客户端开发工程师｜岗位职责描述

## 校招

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与移动端 App 功能模块的开发与维护，保障用户体验、性能与稳定性，协同产品、设计与后端团队完成高质量交付。

## 主要职责

1. 在指导下根据产品需求完成移动端功能开发与 UI 还原，保障交互流畅与版本稳定。
2. 参与客户端架构优化、组件封装与性能调优，提升启动速度、流畅度与崩溃率表现。
3. 与后端协作完成接口联调，定位并修复客户端线上问题，保障核心链路可用性。
4. 参与跟进系统版本适配、权限变更与应用商店发布流程，保障合规上线。
5. 参与代码评审与技术文档编写，沉淀可复用组件与开发规范。

## 任职要求

### 必备条件

- 具备 0–1 年移动端开发相关全职工作经验，有完整 App 项目交付经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 掌握对应平台开发语言与框架，能在指导下完成模块级功能开发。
- 熟悉移动端常见性能优化、网络通信、数据存储与调试手段。
- 具备良好的编码习惯、问题定位能力与跨团队协作意识。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 有跨平台开发（Flutter/React Native 等）经验相关实习或校园项目经历。
- 熟悉音视频、推送、埋点或热修复等相关技术相关实习或校园项目经历。
- 有应用性能监控（APM）与线上问题治理经验相关实习或校园项目经历。

## 中级

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责多端客户端技术栈相关模块或子系统的设计开发与维护，保障系统性能、稳定性与代码质量，对交付效率与技术方案结果负责。

## 主要职责

1. 主导复杂业务模块的技术方案设计与编码实现，保障多端客户端技术栈架构合理性与可维护性。
2. 负责代码评审、技术难点攻关与线上问题排查，推动性能优化、稳定性改进与缺陷闭环。
3. 与产品、测试、运维等团队深度协作，推进需求落地、接口联调与高质量发布。
4. 参与或主导技术规范、工程化建设与组件/服务复用，提升团队研发效率。
5. 输出技术设计文档与复盘总结，沉淀最佳实践并辅导初级工程师成长。

## 任职要求

### 必备条件

- 具备 3–5 年客户端开发或相关技术全职工作经验。
- 精通多端客户端技术栈核心技术，能独立负责复杂模块或子系统的设计与开发。
- 熟悉常见设计模式、数据结构与算法，具备良好的编码规范与问题定位能力。
- 具备出色的跨团队协作与沟通能力，能在项目压力下保障交付质量。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有大型互联网高并发系统开发经验。
- 熟悉 CI/CD、容器化或微服务架构。
- 有技术分享、Code Review 牵头或工程化建设经验。
