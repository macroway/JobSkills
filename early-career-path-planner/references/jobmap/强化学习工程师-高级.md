# 强化学习工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 高级 |
| 工作年限 | 5–8 年 |

## 岗位概述

负责强化学习算法的建模、训练与评估，探索在业务决策与智能控制场景中的应用，推动关键项目落地与方法沉淀。

## 主要职责

1. 主导业务问题的算法建模与方案设计，完成数据预处理、特征工程与模型训练评估。
2. 跟进算法离线/在线实验，分析效果指标，迭代优化模型性能与稳定性。
3. 跨工程团队推动完成模型部署、服务化与性能优化，保障线上效果与资源效率。
4. 跟踪领域前沿技术与论文成果，探索可应用于业务的算法改进方向。
5. 沉淀并推广实验记录、模型文档与评估报告，提升算法研发规范性与可复用性。
6. 辅导初级成员或协作伙伴，沉淀方法论、规范与最佳实践，提升团队整体专业能力与交付效率。

## 任职要求

### 必备条件

- 具备 5–8 年算法、机器学习或数据挖掘相关全职工作经验。
- 扎实的数学、统计与机器学习基础，熟悉常见模型原理与评估方法。
- 熟练使用 Python 及主流机器学习框架，能独立完成模型开发与实验。
- 具备良好的业务理解能力、逻辑思维与跨团队协作意识。
- 硕士及以上学历，计算机、数学、统计学等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备复杂问题分析与决策能力，能在跨团队协作中推动关键事项落地，并辅导初级成员成长。

### 加分项

- 在推荐、搜索、NLP、CV、语音等方向有实际项目经验。
- 熟悉深度学习框架与大规模训练、推理优化技术。
- 有顶会论文、算法竞赛获奖或开源项目贡献。
