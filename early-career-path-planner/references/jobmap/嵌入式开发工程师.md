# 嵌入式开发工程师｜岗位职责描述

## 校招

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与嵌入式系统软件模块的开发、调试与维护，保障设备功能稳定运行，协同硬件、固件与上位机团队完成产品化交付。

## 主要职责

1. 在指导下根据产品需求完成嵌入式软件模块开发与单元测试，保障功能正确性与资源占用可控。
2. 参与硬件联调、驱动适配与通信协议实现，定位并解决软硬件集成问题。
3. 参与编写技术文档与测试用例，参与版本发布、问题复盘与质量改进。
4. 与硬件、测试、产品团队协作，推动需求澄清与问题闭环。
5. 参与关注代码规范、可维护性与功耗/性能优化，沉淀可复用模块与开发经验。

## 任职要求

### 必备条件

- 具备 0–1 年嵌入式开发相关全职工作经验，有实际产品落地经验者优先。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 熟悉 C/C++ 开发，了解 RTOS、驱动开发或常见通信协议。
- 具备硬件联调与问题定位能力，能使用示波器、逻辑分析仪等工具者优先。
- 具备良好的文档能力与跨团队协作意识。
- 本科及以上学历，电子、计算机、自动化等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 有 IoT、智能硬件或工业控制项目经验相关实习或校园项目经历。
- 熟悉 ARM、MCU 等常见芯片平台开发相关实习或校园项目经历。
- 有低功耗优化、OTA 升级或安全启动相关经验相关实习或校园项目经历。

## 中级

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责嵌入式 C/C++相关模块或子系统的设计开发与维护，保障系统性能、稳定性与代码质量，对交付效率与技术方案结果负责。

## 主要职责

1. 主导复杂业务模块的技术方案设计与编码实现，保障嵌入式 C/C++架构合理性与可维护性。
2. 负责代码评审、技术难点攻关与线上问题排查，推动性能优化、稳定性改进与缺陷闭环。
3. 与产品、测试、运维等团队深度协作，推进需求落地、接口联调与高质量发布。
4. 参与或主导技术规范、工程化建设与组件/服务复用，提升团队研发效率。
5. 输出技术设计文档与复盘总结，沉淀最佳实践并辅导初级工程师成长。

## 任职要求

### 必备条件

- 具备 3–5 年嵌入式开发或相关技术全职工作经验。
- 精通嵌入式 C/C++核心技术，能独立负责复杂模块或子系统的设计与开发。
- 熟悉常见设计模式、数据结构与算法，具备良好的编码规范与问题定位能力。
- 具备出色的跨团队协作与沟通能力，能在项目压力下保障交付质量。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有大型互联网高并发系统开发经验。
- 熟悉 CI/CD、容器化或微服务架构。
- 有技术分享、Code Review 牵头或工程化建设经验。
