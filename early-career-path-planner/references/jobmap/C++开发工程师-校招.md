# C++开发工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与服务端业务模块的设计、开发与维护，保障系统稳定性、性能与数据安全，支撑业务功能快速迭代与规模化运行。

## 主要职责

1. 在指导下根据产品需求完成后端接口设计与开发，保障功能正确性、可扩展性与代码质量。
2. 参与数据库表结构设计、SQL 优化与缓存策略设计，提升系统性能与数据一致性。
3. 与前端、测试、运维团队协作，完成联调、测试支持与线上问题排查修复。
4. 参与系统架构讨论与技术方案评审，推动模块级重构与稳定性改进。
5. 参与编写接口文档与技术说明，参与代码评审，沉淀开发规范与可复用能力。

## 任职要求

### 必备条件

- 具备 0–1 年 C++ 开发全职工作经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 掌握 C++ 语言特性、STL 及常见设计模式。
- 熟悉 Linux 开发环境、多线程编程与性能调优基础。
- 具备良好的代码质量意识与问题定位能力。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 有微服务、分布式系统或高并发场景开发经验相关实习或校园项目经历。
- 熟悉 Docker、K8s 等容器化部署与 CI/CD 流程相关实习或校园项目经历。
- 有消息队列、搜索引擎或大数据组件使用经验相关实习或校园项目经历。
