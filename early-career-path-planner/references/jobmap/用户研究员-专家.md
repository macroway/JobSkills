# 用户研究员｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 专家 |
| 工作年限 | 8 年以上 |

## 岗位概述

通过用户访谈、可用性测试与行为数据分析，洞察用户需求与使用场景，为产品设计与业务决策提供可落地的研究结论与体验优化建议，负责关键业务方向或能力建设，推动战略拆解与长期价值落地。

## 主要职责

1. 结合业务目标与行业趋势，参与或负责中长期规划与关键方向拆解，明确能力建设路径与优先级。
2. 负责制定并推动用户研究项目设计与执行，包括访谈、问卷、可用性测试等，输出研究报告与关键洞察。
3. 建立并持续完善用户画像、旅程地图与需求优先级，为产品、设计、运营团队提供决策输入。
4. 跟踪产品上线后的用户反馈与行为数据，识别体验问题并提出改进方向。
5. 在组织层面跨产品、设计、研发推动，推动研究结论转化为具体的产品与体验优化方案。
6. 建立并推广组织级研究方法论、访谈提纲与分析模板，提升团队用户研究效率与质量。
7. 负责关键领域的方法论沉淀、能力体系建设与跨团队影响力构建，推动组织专业能力持续提升。

## 任职要求

### 必备条件

- 具备 8 年以上用户研究、市场研究或体验研究相关全职工作经验。
- 精通定性/定量研究方法，能独立完成调研设计、样本招募与结论输出。
- 具备良好的沟通引导能力与逻辑思维，能清晰呈现研究发现与建议。
- 熟练使用常见调研与分析工具，具备扎实的数据整理与可视化能力。
- 本科及以上学历，心理学、社会学、人机交互、市场营销等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备战略规划、复杂问题分析与关键决策能力，能在跨团队协作中推动关键事项落地，能建立方法论并影响跨团队协作。

### 加分项

- 有 SPSS、Python、R 等数据分析工具使用经验。
- 熟悉互联网 C 端/B 端产品研究场景。
- 具备可用性测试实验室运营或眼动/热力图等工具使用经验。
