# 全栈开发工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 高级 |
| 工作年限 | 5–8 年 |

## 岗位概述

负责前后端一体化功能模块的开发与维护，贯通需求理解、接口设计与页面实现，提升业务交付效率与系统一致性，推动关键项目落地与方法沉淀。

## 主要职责

1. 独立完成业务功能的前后端开发，包括接口设计、页面实现与联调测试。
2. 主导技术选型与模块架构设计，平衡开发效率、可维护性与系统性能。
3. 与产品、设计团队协作，快速验证方案并推动功能迭代上线。
4. 定位并修复全链路问题，保障功能稳定性与用户体验。
5. 沉淀并推广通用组件、脚手架与开发规范，提升团队整体交付效率。
6. 辅导初级成员或协作伙伴，沉淀方法论、规范与最佳实践，提升团队整体专业能力与交付效率。

## 任职要求

### 必备条件

- 具备 5–8 年全栈开发相关全职工作经验，能独立负责核心领域或复杂项目功能交付。
- 熟练掌握至少一种前端框架与一种后端开发语言，具备完整项目开发能力。
- 熟悉数据库设计、API 设计与常见 Web 开发模式。
- 具备良好的学习能力、问题解决能力与跨团队协作意识。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备复杂问题分析与决策能力，能在跨团队协作中推动关键事项落地，并辅导初级成员成长。

### 加分项

- 有 SaaS、管理后台或数据可视化项目经验。
- 熟悉云部署、DevOps 或自动化测试流程。
- 有从 0 到 1 搭建小型系统或内部工具的经验。
