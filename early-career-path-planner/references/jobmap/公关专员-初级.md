# 公关专员｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 初级 |
| 工作年限 | 1–3 年 |

## 岗位概述

负责媒体关系维护、舆情监测与品牌传播活动执行，提升品牌美誉度与公众认知。

## 主要职责

1. 参与市场调研、竞品分析与目标用户洞察，辅助制定市场推广策略与传播计划。
2. 策划并执行品牌活动、广告投放或内容营销方案，跟踪投放效果与 ROI。
3. 维护品牌传播物料、渠道内容与媒体关系，保障品牌信息一致性与传播质量。
4. 与销售、产品、运营团队协作，推动市场活动与业务目标对齐并落地。
5. 输出活动复盘与市场分析报告，沉淀可复用的营销经验与素材资产。

## 任职要求

### 必备条件

- 具备 1–3 年市场营销、品牌推广或广告投放相关全职工作经验。
- 具备良好的市场敏感度、文案能力与项目执行能力。
- 熟悉常见营销渠道与基础投放逻辑，具备数据分析意识。
- 沟通表达清晰，具备跨部门协作与抗压能力。
- 本科及以上学历，市场营销、广告、新闻传播等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有 SEM/SEO、社交媒体投放或整合营销项目经验。
- 熟悉营销自动化工具或数据归因分析方法。
- 有 B 端或 C 端品牌传播成功案例。
