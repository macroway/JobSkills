# 机器人算法工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与机器人感知、规划或控制相关算法的研发与验证，推动算法在硬件平台上的工程化落地。

## 主要职责

1. 参与业务问题的算法建模与方案设计，完成数据预处理、特征工程与模型训练评估。
2. 参与跟进算法离线/在线实验，分析效果指标，迭代优化模型性能与稳定性。
3. 与工程团队协作完成模型部署、服务化与性能优化，保障线上效果与资源效率。
4. 跟踪领域前沿技术与论文成果，探索可应用于业务的算法改进方向。
5. 参与沉淀实验记录、模型文档与评估报告，提升算法研发规范性与可复用性。

## 任职要求

### 必备条件

- 具备 0–1 年算法、机器学习或数据挖掘相关全职工作经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 扎实的数学、统计与机器学习基础，熟悉常见模型原理与评估方法。
- 了解 Python 及主流机器学习框架，能在指导下完成模型开发与实验。
- 具备良好的业务理解能力、逻辑思维与跨团队协作意识。
- 硕士及以上学历，计算机、数学、统计学等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 在推荐、搜索、NLP、CV、语音等方向有实际项目经验相关实习或校园项目经历。
- 熟悉深度学习框架与大规模训练、推理优化技术相关实习或校园项目经历。
- 有顶会论文、算法竞赛获奖或开源项目贡献相关实习或校园项目经历。
