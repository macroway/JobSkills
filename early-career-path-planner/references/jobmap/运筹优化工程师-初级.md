# 运筹优化工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 初级 |
| 工作年限 | 1–3 年 |

## 岗位概述

负责调度、路径规划、资源分配等运筹优化问题的建模与求解，提升业务运营效率。

## 主要职责

1. 参与业务问题的算法建模与方案设计，完成数据预处理、特征工程与模型训练评估。
2. 跟进算法离线/在线实验，分析效果指标，迭代优化模型性能与稳定性。
3. 与工程团队协作完成模型部署、服务化与性能优化，保障线上效果与资源效率。
4. 跟踪领域前沿技术与论文成果，探索可应用于业务的算法改进方向。
5. 沉淀实验记录、模型文档与评估报告，提升算法研发规范性与可复用性。

## 任职要求

### 必备条件

- 具备 1–3 年算法、机器学习或数据挖掘相关全职工作经验。
- 扎实的数学、统计与机器学习基础，熟悉常见模型原理与评估方法。
- 熟练使用 Python 及主流机器学习框架，能独立完成模型开发与实验。
- 具备良好的业务理解能力、逻辑思维与跨团队协作意识。
- 硕士及以上学历，计算机、数学、统计学等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 在推荐、搜索、NLP、CV、语音等方向有实际项目经验。
- 熟悉深度学习框架与大规模训练、推理优化技术。
- 有顶会论文、算法竞赛获奖或开源项目贡献。
