# 客户端开发工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 初级 |
| 工作年限 | 1–3 年 |

## 岗位概述

负责移动端 App 功能模块的开发与维护，保障用户体验、性能与稳定性，协同产品、设计与后端团队完成高质量交付。

## 主要职责

1. 根据产品需求完成移动端功能开发与 UI 还原，保障交互流畅与版本稳定。
2. 参与客户端架构优化、组件封装与性能调优，提升启动速度、流畅度与崩溃率表现。
3. 与后端协作完成接口联调，定位并修复客户端线上问题，保障核心链路可用性。
4. 跟进系统版本适配、权限变更与应用商店发布流程，保障合规上线。
5. 参与代码评审与技术文档编写，沉淀可复用组件与开发规范。

## 任职要求

### 必备条件

- 具备 1–3 年移动端开发相关全职工作经验，有完整 App 项目交付经验。
- 熟练掌握对应平台开发语言与框架，能独立完成模块级功能开发。
- 熟悉移动端常见性能优化、网络通信、数据存储与调试手段。
- 具备良好的编码习惯、问题定位能力与跨团队协作意识。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有跨平台开发（Flutter/React Native 等）经验。
- 熟悉音视频、推送、埋点或热修复等相关技术。
- 有应用性能监控（APM）与线上问题治理经验。
