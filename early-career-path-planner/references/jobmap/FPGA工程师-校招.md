# FPGA工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与 FPGA 逻辑设计、仿真验证与板级调试，推动硬件加速方案落地。

## 主要职责

1. 参与硬件电路设计、原理图绘制、PCB 布局或器件选型，完成模块级开发与验证。
2. 参与进行硬件调试、测试与问题定位，输出测试报告并推动问题闭环。
3. 与结构、嵌入式、测试团队协作，保障软硬件联调与整机交付质量。
4. 参与编写硬件设计文档、BOM 清单与技术规范，支持量产导入与维护。
5. 参与关注成本、可靠性与可制造性，持续优化硬件方案与工艺流程。

## 任职要求

### 必备条件

- 具备 0–1 年硬件开发、电子工程或物联网相关全职工作经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 熟悉模拟/数字电路设计，能使用常见 EDA 工具完成基础设计工作。
- 具备硬件调试与问题分析能力，了解常见测试仪器使用方法。
- 具备良好的跨团队协作能力与文档习惯。
- 本科及以上学历，电子、通信、自动化等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 有消费电子、IoT 或工业控制硬件项目经验相关实习或校园项目经历。
- 熟悉 EMC、安规认证或量产导入流程相关实习或校园项目经历。
- 有 FPGA、射频或天线设计相关经验相关实习或校园项目经历。
