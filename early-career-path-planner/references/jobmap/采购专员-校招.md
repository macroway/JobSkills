# 采购专员｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与供应商管理、采购流程执行与成本分析，保障物资/服务采购合规高效。

## 主要职责

1. 执行费用报销、账务处理、预算跟踪或行政采购等日常事务，确保流程合规与数据准确。
2. 协助编制基础财务报表、经营分析材料或行政管理制度文档。
3. 参与对接内外部相关方，处理日常咨询、审批与协调事项，保障事务及时闭环。
4. 维护档案、合同、资产或办公环境等基础管理工作，提升运营效率。
5. 参与流程优化与内控检查，提出改进建议并推动落地。

## 任职要求

### 必备条件

- 具备 0–1 年财务、会计或行政相关全职工作经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 工作细致严谨，具备良好的责任心与数据准确性意识。
- 了解 Excel 及常见财务/办公系统，具备基础文档撰写能力。
- 具备良好的沟通协作与服务意识。
- 本科及以上学历，财务、会计、行政管理等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 持有初级会计职称或相关从业资格相关实习或校园项目经历。
- 有互联网公司财务共享或行政综合支持经验相关实习或校园项目经历。
- 熟悉 ERP、费控系统或合同管理经验相关实习或校园项目经历。
