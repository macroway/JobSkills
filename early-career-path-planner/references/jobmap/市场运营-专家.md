# 市场运营｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 专家 |
| 工作年限 | 8 年以上 |

## 岗位概述

负责品牌营销、市场推广或广告投放相关工作，通过市场洞察与传播策略提升品牌认知与业务转化，协同销售与产品团队实现增长目标，负责关键业务方向或能力建设，推动战略拆解与长期价值落地。

## 主要职责

1. 结合业务目标与行业趋势，参与或负责中长期规划与关键方向拆解，明确能力建设路径与优先级。
2. 参与市场调研、竞品分析与目标用户洞察，负责制定并推动制定市场推广策略与传播计划。
3. 策划并执行品牌活动、广告投放或内容营销方案，建立投放效果评估体系，跟踪投放效果与 ROI。
4. 维护品牌传播物料、渠道内容与媒体关系，保障品牌信息一致性与传播质量。
5. 与销售、产品、运营团队协作，推动市场活动与业务目标对齐并落地。
6. 输出活动复盘与市场分析报告，负责制定并推动沉淀可复用的营销经验与素材资产。
7. 负责关键领域的方法论沉淀、能力体系建设与跨团队影响力构建，推动组织专业能力持续提升。

## 任职要求

### 必备条件

- 具备 8 年以上市场营销、品牌推广或广告投放相关全职工作经验。
- 具备良好的市场敏感度、文案能力与项目执行能力。
- 精通常见营销渠道与基础投放逻辑，具备数据分析意识。
- 沟通表达清晰，具备跨部门协作与抗压能力。
- 本科及以上学历，市场营销、广告、新闻传播等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备战略规划、复杂问题分析与关键决策能力，能在跨团队协作中推动关键事项落地，能建立方法论并影响跨团队协作。

### 加分项

- 有 SEM/SEO、社交媒体投放或整合营销项目经验。
- 熟悉营销自动化工具或数据归因分析方法。
- 有 B 端或 C 端品牌传播成功案例。
