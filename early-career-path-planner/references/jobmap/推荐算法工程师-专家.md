# 推荐算法工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 专家 |
| 工作年限 | 8 年以上 |

## 岗位概述

负责推荐系统召回、排序等算法的研发与迭代，提升推荐效果与用户体验，负责关键业务方向或能力建设，推动战略拆解与长期价值落地。

## 主要职责

1. 结合业务目标与行业趋势，参与或负责中长期规划与关键方向拆解，明确能力建设路径与优先级。
2. 负责制定并推动业务问题的算法建模与方案设计，完成数据预处理、特征工程与模型训练评估。
3. 跟进算法离线/在线实验，分析效果指标，迭代优化模型性能与稳定性。
4. 跨工程团队推动完成模型部署、服务化与性能优化，保障线上效果与资源效率。
5. 跟踪领域前沿技术与论文成果，探索可应用于业务的算法改进方向。
6. 建立并推广组织级实验记录、模型文档与评估报告，提升算法研发规范性与可复用性。
7. 负责关键领域的方法论沉淀、能力体系建设与跨团队影响力构建，推动组织专业能力持续提升。

## 任职要求

### 必备条件

- 具备 8 年以上算法、机器学习或数据挖掘相关全职工作经验。
- 扎实的数学、统计与机器学习基础，精通常见模型原理与评估方法。
- 熟练使用 Python 及主流机器学习框架，能独立完成模型开发与实验。
- 具备良好的业务理解能力、逻辑思维与跨团队协作意识。
- 硕士及以上学历，计算机、数学、统计学等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备战略规划、复杂问题分析与关键决策能力，能在跨团队协作中推动关键事项落地，能建立方法论并影响跨团队协作。

### 加分项

- 在推荐、搜索、NLP、CV、语音等方向有实际项目经验。
- 熟悉深度学习框架与大规模训练、推理优化技术。
- 有顶会论文、算法竞赛获奖或开源项目贡献。
