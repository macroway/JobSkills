# 社区运营｜岗位职责描述

## 校招

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与社区氛围建设、用户互动与UGC生态运营，提升社区活跃度与内容供给质量。

## 主要职责

1. 参与运营策略制定与执行，围绕拉新、活跃、转化、留存等目标推进具体方案落地。
2. 跟踪核心运营数据，分析活动或策略效果，输出复盘报告并持续优化。
3. 参与策划并执行运营活动、内容计划或用户触达方案，提升用户参与度和业务转化。
4. 与产品、设计、市场、客服等团队协作，推动运营需求闭环与体验改进。
5. 参与沉淀运营 SOP、活动模板与方法论，提升团队运营效率与可复制性。

## 任职要求

### 必备条件

- 具备 0–1 年互联网运营相关全职工作经验，有独立负责模块或项目的经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 具备数据敏感度，能使用 Excel、SQL 等工具进行基础数据分析。
- 具备良好的文案能力、执行力与跨团队沟通协作能力。
- 对互联网业务模式有基本理解，能快速学习并适应业务变化。
- 本科及以上学历，市场营销、新闻传播、电子商务等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有电商、内容、社区、直播或增长运营相关经验相关实习或校园项目经历。
- 熟悉 A/B 测试、用户分层或私域运营方法相关实习或校园项目经历。
- 有从 0 到 1 搭建运营体系或爆款活动案例相关实习或校园项目经历。

## 中级

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责社区运营策略制定与执行，通过精细化运营提升核心指标，对增长、活跃、留存或转化结果负责。

## 主要职责

1. 主导社区运营策略设计与活动策划，制定可量化的运营目标并推动落地。
2. 建立运营数据监控体系，跟踪核心指标波动，通过数据分析驱动策略迭代与效果优化。
3. 负责用户分层、社群、内容或渠道等运营动作执行，提升用户活跃与转化效率。
4. 与产品、市场、技术等团队深度协作，推动运营需求落地与流程标准化。
5. 输出运营复盘报告与方法论沉淀，指导初级运营同学提升策略设计与执行能力。

## 任职要求

### 必备条件

- 具备 3–5 年互联网运营全职工作经验。
- 熟悉社区运营方法论，能独立负责复杂运营项目或专项。
- 具备数据分析能力，熟练使用 Excel/SQL 等工具进行指标监控与归因分析。
- 具备出色的创意策划、沟通协作与项目推进能力。
- 本科及以上学历；学历要求可根据实际招聘要求调整。

### 加分项

- 有用户增长、电商、内容、游戏等垂直领域运营经验。
- 有从 0 到 1 搭建运营体系或 SOP 经验。
- 熟悉 A/B 测试或精细化运营工具。
