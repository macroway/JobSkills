# SEM专员｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责SEM专员相关市场策略制定与执行，提升品牌认知与获客效果，对传播质量与 ROI 负责。

## 主要职责

1. 主导市场调研、竞品分析与目标用户洞察，制定市场推广策略与传播计划。
2. 策划并执行品牌活动、广告投放或内容营销方案，跟踪投放效果并持续优化 ROI。
3. 维护品牌传播物料、媒体关系与渠道内容，保障品牌信息一致性与传播质量。
4. 与销售、产品、运营团队深度协作，推动市场活动与业务目标对齐并落地。
5. 输出活动复盘与市场分析报告，沉淀可复用的营销经验与素材资产。

## 任职要求

### 必备条件

- 具备 3–5 年市场营销、品牌推广或广告投放全职工作经验。
- 具备良好的市场敏感度、文案能力与项目执行能力。
- 熟悉主流营销渠道与投放逻辑，具备数据分析与效果归因意识。
- 沟通表达清晰，具备跨部门协作与抗压能力。
- 本科及以上学历，市场营销、广告、新闻传播等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有 SEM/SEO、社交媒体投放或整合营销项目经验。
- 熟悉营销自动化工具或数据归因分析方法。
- 有 B 端或 C 端品牌传播成功案例。
