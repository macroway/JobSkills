# 竞品分析师｜岗位职责描述

## 校招

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，参与竞品动态跟踪、功能对比与市场分析，为产品战略与业务决策提供参考输入。

## 主要职责

1. 参与用户研究项目设计与执行，包括访谈、问卷、可用性测试等，输出研究报告与关键洞察。
2. 协助建立用户画像、旅程地图与需求优先级，为产品、设计、运营团队提供决策输入。
3. 跟踪产品上线后的用户反馈与行为数据，识别体验问题并提出改进方向。
4. 与产品、设计、研发团队协作，推动研究结论转化为具体的产品与体验优化方案。
5. 参与沉淀研究方法论、访谈提纲与分析模板，提升团队用户研究效率与质量。

## 任职要求

### 必备条件

- 具备 0–1 年用户研究、市场研究或体验研究相关全职工作经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 熟悉定性/定量研究方法，能在指导下完成调研设计、样本招募与结论输出。
- 具备良好的沟通引导能力与逻辑思维，能清晰呈现研究发现与建议。
- 了解常见调研与分析工具，具备基础数据整理与可视化能力。
- 本科及以上学历，心理学、社会学、人机交互、市场营销等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 有 SPSS、Python、R 等数据分析工具使用经验相关实习或校园项目经历。
- 熟悉互联网 C 端/B 端产品研究场景相关实习或校园项目经历。
- 具备可用性测试实验室运营或眼动/热力图等工具使用经验相关实习或校园项目经历。

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 中级 |
| 工作年限 | 3–5 年 |

## 岗位概述

负责竞品与市场情报收集分析，为产品、战略与运营决策提供客观洞察，对分析深度与时效性负责。

## 主要职责

1. 主导竞品功能、策略、商业模式与数据表现跟踪，输出结构化竞品分析报告。
2. 建立竞品监控机制与情报库，及时识别行业变化与机会威胁。
3. 与产品、市场、战略团队深度协作，将竞品洞察转化为可执行建议。
4. 组织竞品分享与讨论，推动团队对竞争格局形成共识。
5. 沉淀竞品分析框架、模板与数据源，提升团队分析效率。

## 任职要求

### 必备条件

- 具备 3–5 年竞品分析、市场研究或战略分析全职工作经验。
- 具备敏锐的行业洞察力与结构化分析能力。
- 熟悉常用调研工具与信息获取渠道，报告撰写能力强。
- 本科及以上学历；学历要求可根据实际招聘要求调整。

### 加分项

- 有互联网产品或战略分析经验。
- 具备数据分析或用户研究配合经验。
