# Java开发工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 专家 |
| 工作年限 | 8 年以上 |

## 岗位概述

负责服务端业务模块的设计、开发与维护，保障系统稳定性、性能与数据安全，支撑业务功能快速迭代与规模化运行，负责关键业务方向或能力建设，推动战略拆解与长期价值落地。

## 主要职责

1. 结合业务目标与行业趋势，参与或负责中长期规划与关键方向拆解，明确能力建设路径与优先级。
2. 根据产品需求完成后端接口设计与开发，保障功能正确性、可扩展性与代码质量。
3. 负责制定并推动数据库表结构设计、SQL 优化与缓存策略设计，提升系统性能与数据一致性。
4. 与前端、测试、运维团队协作，完成联调、测试支持与线上问题排查修复。
5. 负责制定并推动系统架构讨论与技术方案评审，推动模块级重构与稳定性改进。
6. 编写接口文档与技术说明，负责制定并推动代码评审，沉淀开发规范与可复用能力。
7. 负责关键领域的方法论沉淀、能力体系建设与跨团队影响力构建，推动组织专业能力持续提升。

## 任职要求

### 必备条件

- 具备 8 年以上 Java 后端开发全职工作经验，有 Spring/Spring Boot 项目经验。
- 熟练掌握 Java 语言及常用框架，精通 MySQL 与 Redis 等中间件。
- 精通 RESTful API 设计、Maven/Gradle 及 Git 协作流程。
- 具备良好的编码习惯、问题定位与跨团队协作能力。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备战略规划、复杂问题分析与关键决策能力，能在跨团队协作中推动关键事项落地，能建立方法论并影响跨团队协作。

### 加分项

- 有微服务、分布式系统或高并发场景开发经验。
- 熟悉 Docker、K8s 等容器化部署与 CI/CD 流程。
- 有消息队列、搜索引擎或大数据组件使用经验。
