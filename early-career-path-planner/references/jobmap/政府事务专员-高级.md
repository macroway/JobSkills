# 政府事务专员｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 高级 |
| 工作年限 | 5–8 年 |

## 岗位概述

负责政府关系维护、政策信息跟踪与政务项目对接，支持公司合规经营与政策资源获取，推动关键项目落地与方法沉淀。

## 主要职责

1. 独立起草并审核、审核合同及法律文件，参与商务条款评审与风险提示。
2. 持续跟踪法律法规、行业监管政策变化，输出合规指引并推动业务整改。
3. 主导内控检查、审计配合或政府事务对接，整理材料并跟进问题闭环。
4. 跨业务、财务、人力等部门推动，将合规要求融入日常业务流程。
5. 维护法务/合规知识库与档案，主导沉淀标准模板与操作规范。
6. 辅导初级成员或协作伙伴，沉淀方法论、规范与最佳实践，提升团队整体专业能力与交付效率。

## 任职要求

### 必备条件

- 具备 5–8 年法务、合规、审计或政府事务相关全职工作经验。
- 具备扎实的法律或合规基础知识，工作细致、逻辑清晰。
- 具备良好的沟通能力、文档撰写能力与跨部门协作意识。
- 责任心强，能在压力下保障事项按时推进。
- 本科及以上学历，法学、审计、公共管理等相关专业优先；学历要求可根据实际招聘要求调整。
- 具备复杂问题分析与决策能力，能在跨团队协作中推动关键事项落地，并辅导初级成员成长。

### 加分项

- 通过法律职业资格考试或持有相关合规认证。
- 有互联网、科技行业合规或数据合规经验。
- 有政府项目申报或政企合作对接经验。
