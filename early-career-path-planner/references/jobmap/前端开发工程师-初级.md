# 前端开发工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 初级 |
| 工作年限 | 1–3 年 |

## 岗位概述

负责 Web/H5 等前端模块的设计开发与维护，保障页面性能、交互体验与代码质量，协同产品与后端团队高质量交付业务功能。

## 主要职责

1. 根据产品需求与 UI 设计稿，独立完成前端页面与交互功能开发，保障高保真还原。
2. 参与前端组件封装、代码规范与工程化建设，提升开发效率与可维护性。
3. 与后端协作完成接口联调，定位并修复前后端集成问题，保障功能稳定上线。
4. 参与前端性能优化、兼容性适配与线上问题排查，持续改进用户体验与系统稳定性。
5. 编写必要的技术文档，参与代码评审，沉淀可复用组件与最佳实践。

## 任职要求

### 必备条件

- 具备 1–3 年前端开发相关全职工作经验，有完整项目交付经验。
- 精通 HTML、CSS、JavaScript/TypeScript，熟悉 ES6+ 语法与常见前端开发模式。
- 熟练使用 Vue 或 React 等主流框架，了解前端工程化工具（Webpack/Vite 等）。
- 熟悉 Git 协作流程，具备良好的编码习惯、问题定位与沟通能力。
- 本科及以上学历，计算机、软件工程等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 有小程序、跨端开发或 Node.js 中间层开发经验。
- 熟悉前端性能优化、自动化测试或 CI/CD 流程。
- 有组件库建设、低代码平台或 AI 辅助开发工具使用经验。
