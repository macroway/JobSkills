# 售前咨询顾问｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 校招 |
| 工作年限 | 0–1 年 |

## 岗位概述

在导师或资深同事指导下，为客户提供技术咨询、解决方案设计或售前支持服务，理解业务痛点并输出可落地的技术/产品方案，协同销售与交付团队推动项目成交与落地。

## 主要职责

1. 参与客户需求调研与现状分析，输出解决方案、技术建议书或投标文件。
2. 参与进行产品演示、技术交流与方案讲解，解答客户技术与业务问题。
3. 参与协同销售、产品、研发团队，推动方案定制、 POC 验证与项目交付衔接。
4. 跟踪行业趋势与竞品动态，沉淀行业方案模板与最佳实践。
5. 参与项目复盘与客户关系维护，持续优化方案能力与服务质量。

## 任职要求

### 必备条件

- 具备 0–1 年技术咨询、售前或解决方案相关全职工作经验。；或应届毕业生/实习转正候选人，有相关实习或课程项目经验者优先。
- 具备良好的业务理解能力、逻辑思维与方案撰写/演讲能力。
- 熟悉所负责产品或技术领域的基础架构与应用场景。
- 具备良好的客户沟通、跨团队协作与抗压能力。
- 本科及以上学历，计算机、软件工程、信息管理等相关专业优先；学历要求可根据实际招聘要求调整。
- 学习能力强，沟通表达清晰，团队协作意识强，能在指导下按时完成分配任务并虚心接受反馈。

### 加分项

- 有 ToB 软件、云计算、大数据或 AI 解决方案经验相关实习或校园项目经历。
- 持有云平台或厂商相关技术认证相关实习或校园项目经历。
- 有行业客户项目成功落地案例相关实习或校园项目经历。
