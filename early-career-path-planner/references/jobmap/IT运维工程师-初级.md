# IT运维工程师｜岗位职责描述

## 岗位信息

| 项目 | 内容 |
| --- | --- |
| 职级/类型 | 初级 |
| 工作年限 | 1–3 年 |

## 岗位概述

负责系统、网络或平台的运维保障工作，确保服务稳定、安全、高效运行，支撑业务持续交付与故障快速恢复。

## 主要职责

1. 负责服务器、网络、数据库或云资源的日常运维、监控告警与巡检，保障系统可用性。
2. 参与故障应急响应、问题定位与恢复，编写故障报告并推动根因修复与预防改进。
3. 执行发布变更、容量评估与性能优化，保障变更过程可控、风险可追踪。
4. 与研发、测试、安全团队协作，完善运维规范、自动化脚本与文档体系。
5. 参与运维平台、监控体系或自动化工具建设，提升运维效率与标准化水平。

## 任职要求

### 必备条件

- 具备 1–3 年运维、DevOps 或 SRE 相关全职工作经验。
- 熟悉 Linux 操作系统、网络基础与常见中间件运维。
- 了解监控告警、日志分析与故障排查的基本方法。
- 具备良好的责任心、抗压能力与跨团队协作意识。
- 本科及以上学历，计算机、网络工程等相关专业优先；学历要求可根据实际招聘要求调整。

### 加分项

- 熟悉 Docker、K8s、Terraform 等云原生技术。
- 有 Python/Shell 自动化脚本开发经验。
- 有大规模分布式系统或高可用架构运维经验。
